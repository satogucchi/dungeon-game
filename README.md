# 🏰 ПОДЗЕМЕЛЬЕ

Текстовая RPG (dungeon crawler) на чистом Python. Без сторонних библиотек — только стандартная библиотека: `json`, `os`, `random`, `unittest`.

Проект развивается микро-спринтами по 30–60 минут в день: **один день = одна фича = один коммит**.

## 🎮 О игре

Ты — герой, спустившийся в подземелье, полное монстров, ловушек и сокровищ.
Цель: пройти через 12 комнат, найти ключ от Тронного зала и повергнуть Короля Скелетов.

### Возможности
- ⚔️ Пошаговый бой: критические удары, побег, отдых
- 👹 7 видов монстров, мини-босс (Тролль) и финальный босс (Король Скелетов)
- 🗡️ Экипировка: оружие и броня с бонусами к атаке и защите
- 🎒 Инвентарь, зелья лечения, лут с монстров
- 🏪 Торговец: покупка и продажа предметов
- 📜 Квесты от NPC с наградами
- 🗺️ 12 комнат: запертые двери, ключи, секретные проходы
- ✨ Случайные события при переходах: ловушки, тайники, призраки
- 🏆 Таблица рекордов (топ-10) с подсчётом очков
- ⚙️ Три уровня сложности: Легко / Нормально / Кошмар
- 🌈 ANSI-цвета в терминале
- 💾 Сохранение и загрузка игры (JSON)
- 👑 Экран победы и свободная игра после прохождения

## 🚀 Как запустить

### Windows
Двойной клик по `run.bat` — скрипт сам создаст виртуальное окружение и запустит игру.

Вручную:
```bash
python -m venv .venv
.venv\Scripts\activate
python main.py
